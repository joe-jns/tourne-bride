# Centre Protestant Tourne-Bride

Site du Centre Protestant Tourne-Bride (asbl) — centre chrétien pour enfants au cœur du parc naturel de la Haute Sambre, depuis 1964.

Construit avec **Astro**, **Tailwind CSS v4** et **Motion**.

## Développement
```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # -> dist/
```

Le site est déployé sur GitHub Pages : https://joe-jns.github.io/tourne-bride/
